# Bouncy Bowling

A cozy, kid-friendly 2.5D 10-frame bowling game with always-on bouncy bumpers, simple touch controls, and a big **TURKEY!** celebration for 3 strikes in a row.

- **Live site:** https://sofakodev.github.io/bowling/
- **Ruleset:** Classic 10-frame bowling (strikes, spares, 10th-frame bonus rolls) with kid-generous bumper & pin physics.
- **Controls:** Drag in the bottom Approach Zone (behind the red foul line) to position the ball, then flick/push upward to roll — or use **Left/Right Arrow keys + Space** on desktop.

## Local Development

```powershell
npm install
npm run dev
```

## Tests & Production Build

```powershell
npm test
npm run build
```
